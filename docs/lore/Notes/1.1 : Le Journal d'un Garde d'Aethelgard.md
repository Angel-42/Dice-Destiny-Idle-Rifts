Note de Journal 1.1 : Le Journal d'un Garde d'Aethelgard. Lieu : Les Geôles du Soleil. "Le ciel a changé de couleur trois fois ce matin. Le prisonnier dans la cellule 402 ne mange rien, il se contente de fixer le vide. Elio dit que c'est une 'coquille vide', mais j'ai vu ses mains briller d'une lueur violette quand il dort. Si c'est vraiment lui, le Déserteur des légendes, alors les murs de pierre ne suffiront pas à le retenir."
