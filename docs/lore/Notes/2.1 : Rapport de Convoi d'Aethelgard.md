Note de Journal 2.1 : Rapport de Convoi d'Aethelgard. Lieu : Les Marches Grises. "Le passage par les Marches Grises est un suicide. Le sable dévore les roues des charrettes et l'air sent le métal brûlé. Nous avons croisé une femme avec deux sabres qui cherchait quelqu'un. Elle n'a pas voulu dire son nom, mais l'ombre derrière elle semblait bouger toute seule. Elle cherche le Déserteur, elle aussi."
